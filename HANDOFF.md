# HANDOFF — лендинг «Эрклёз»

Документ передачи проекта: что это, как устроено, какие решения приняты и почему,
что готово и что осталось. Рассчитан на то, что читающий видит проект впервые.

Последнее обновление: август 2026.

## 1. О проекте

Одностраничный сайт компании «Эрклёз» — прямого переработчика декоративного кускового
стекла (эрклёза). Продают от 1 камня частникам до 100+ тонн бизнесу, работают с НДС,
отгружают с двух площадок по всей России.

**Цель сайта:** получать заявки. Основной канал привлечения — Яндекс.Директ, поэтому
приоритеты: скорость, честность контента (модерация), корректная аналитика конверсий.

**Две аудитории:**
- частник — сад, ландшафт, камин, интерьер, съёмка; покупает штучно или до тонны;
- бизнес — опт от 10 тонн, НДС, закрывающие документы, тендеры.

Разделение реализовано не переключателем в шапке (его убрали как бесполезный), а
ветвлением внутри квиза — пользователь сам выбирает на первом шаге.

**Планируемый домен:** erklez.ru (пока не куплен).

### Запуск локально

```bash
cd erklez
npm install
npm run dev        # http://localhost:3000
```

**Важно при переносе:** не копируйте `node_modules` и `package-lock.json` со старой
машины — на исходной машине они оказались повреждены и давали ошибки
`Cannot find module 'util-deprecate'` и `npm error Invalid Version`. Если такое
повторится:

```bash
rm -rf node_modules package-lock.json   # PowerShell: Remove-Item -Recurse -Force node_modules
npm install
```

Прочие команды: `npm run build`, `npm start`, `npm run lint`, `npm run typecheck`.

> ⚠️ Полноценный `npm run build` **ни разу не прогонялся** — в среде, где велась
> разработка, не было рабочего `node_modules`. Синтаксис и связи проверялись вручную.
> **Первое, что нужно сделать на новой машине: `npm install && npm run build`.**

## 4. Ключевые решения и почему

**Контент отделён от вёрстки.** Всё, что меняется, лежит в `content/*.ts`. Компоненты
ничего не хардкодят. Это позволяет менять тексты/цены/фото без правки разметки и позже
подключить CMS без переписывания UI.

**Sanity подключён «про запас».** `lib/content-source.ts` — единая точка: если Sanity
сконфигурирован (заданы env), контент берётся оттуда, иначе — из файлов. Сейчас
работают файлы. Роут `/studio` существует, но закрыт от индексации.

**Заявки идут в Telegram, а не на почту.** Мгновенно, без спам-фильтров, менеджер видит
на телефоне. Схема заявки одна (`types/lead.ts`) и на клиенте, и на сервере.

**Анимации на framer-motion, gsap удалён.** В зависимостях был gsap, который нигде не
использовался — выкинут, чтобы не тянуть лишнее.

**Бегущая лента фото — чистый CSS.** Никакой карусельной библиотеки: дублированный
список + `animate-marquee`, пауза при наведении, остановка при reduced-motion.

### Что пробовали и отвергли (чтобы не изобретать заново)

| Что | Почему отказались |
|---|---|
| Sticky-герой со скролл-скрабом видео (стекло трескается → распадается) | Нужное видео не получилось сгенерировать в Higgsfield; решили не усложнять. Бриф на генерацию остался в `../Docs/HERO_ВИДЕО_HIGGSFIELD.md` |
| Скролл-сцена «палитра» (цвета выезжают снизу) | Удалена вместе с откатом героя |
| Интерактивная карта складов (Яндекс.Карты) | Точных адресов нет; фейковые точки вредны. Заменено текстом про две площадки |
| Калькулятор объёма | Убран по просьбе владельца — расчёт делается в квизе |
| Блок «Авторские глыбы» | Убран по просьбе владельца |
| Переключатель «Частнику / Бизнесу» в шапке | Бесполезен: выбор всё равно делается в квизе |
| Блок «Наши работы и документы» (кейсы) | Кейсы были **вымышленные** + стоковые фото. Для рекламы это недостоверные заявления → удалён, заменён лентой реальных фото |
| Space Mono (шрифт из макета) | **Не поддерживает кириллицу** — русские подписи ломались на системный шрифт. Заменён на JetBrains Mono |

## 5. Дизайн-система

Источник — дизайн-проект `../Эрклёз - лендинг.dc.html` (открывается в браузере).

**Шрифты** (подключены через `next/font/google` в `app/layout.tsx`):
- `--font-sans` — **Manrope** (тело текста), латиница + кириллица;
- `--font-display` — **Cormorant**, serif, для всех заголовков; курсив используется как
  акцент («из печи» в H1);
- `--font-mono` — **JetBrains Mono**, для нумерованных подписей-eyebrow и цифр.

> Не заменяйте моношрифт на Space Mono из макета — у него нет кириллицы (проверено по
> метаданным Google Fonts).

**Цвета** (`tailwind.config.ts`):
- `paper` `#F6F4EF` — тёплый «бумажный» фон светлых секций;
- `graphite` — 50/700/800/900/950, тёмные секции и текст;
- `turquoise` `#0E7490` — основной акцент, кнопки, полоса доверия;
- `aqua` `#67E8F9` / `aqua-bright` `#22D3EE` — акценты на тёмном фоне;
- `champagne`, `emerald` — детали.

**Паттерн секции** (соблюдать при добавлении новых):

```tsx
<span className="font-mono text-[13px] uppercase tracking-[0.14em] text-turquoise">
  0N — Название
</span>
<h2 className="mt-3.5 font-display text-[clamp(34px,4.5vw,60px)] font-medium leading-[1.02]">
  Заголовок
</h2>
```

Заголовки **всегда прижаты влево** по общей сетке. Содержимое квиза и FAQ при этом
центрировано — так просил владелец.

**Отступы секций:** `py-14 md:py-20`. Специально уменьшены — исходные были слишком
разрежены.

**Анимации** (`tailwind.config.ts`): `sweep` (бирюзовый свет в герое), `pulse-dot`,
`marquee` (лента фото 60 с), `fade-up`.

## 8. Аналитика и реклама

**Яндекс.Метрика** — `components/analytics/YandexMetrika.tsx`, ID берётся из
`NEXT_PUBLIC_YM_ID`. Пока переменная пуста, счётчик не подключается вообще.

**Цели** (`lib/metrika.ts`) — завести в интерфейсе Метрики с ровно такими
идентификаторами:

| Цель | Когда срабатывает |
|---|---|
| `lead_submit` | успешная отправка формы заявки |
| `contact_telegram` | клик по Telegram в плавающей панели |
| `contact_whatsapp` | клик по WhatsApp |
| `contact_phone` | клик по телефону |

**Рекламные метки.** `lib/utm.ts` при первом заходе ловит из URL `utm_source`,
`utm_medium`, `utm_campaign`, `utm_content`, `utm_term` и `yclid` (идентификатор клика
Директа), кладёт в sessionStorage и подмешивает в каждую заявку. В Telegram приходит
отдельный блок «📣 Реклама» — видно, какое объявление принесло лид. Работает и для
короткой формы, и для квиза.

**Важно:** счётчик грузится только после согласия на аналитические cookie (см. ниже).
Это осознанный компромисс: требование закона против полноты данных.

## 9. Юридическая часть

**Cookie-баннер** (`lib/consent.ts`, `components/consent/`). Основания:
- cookie, позволяющие выделить пользователя, относятся к персональным данным → 152-ФЗ;
- с 01.09.2025 ФЗ-156 требует **явного согласия** на аналитические и рекламные трекеры;
- простого уведомления «мы используем cookie» недостаточно — нужна возможность отказа;
- срок действия согласия — **не более 12 месяцев**, затем спрашиваем снова.

Реализация: две равнозначные кнопки («Принять все» / «Только необходимые»), решение
хранится в localStorage с меткой времени и истекает через 365 дней, изменить решение
можно через «Настройки cookie» в подвале. До согласия скрипты Метрики не загружаются.

**Политика обработки ПДн** — `app/privacy/page.tsx`, 7 разделов, включая таблицу
категорий cookie (якорь `#cookies`, на него ведёт баннер). Реквизиты подтягиваются из
`content/site.ts`.

**Согласие в формах** — чекбокс `ConsentCheckbox`, без него отправка блокируется.

> ⚠️ **Два обязательных действия перед запуском рекламы:**
> 1. Показать политику юристу — типовые шаблоны штрафуют, если они не описывают
>    реальные формы сайта.
> 2. Подать в Роскомнадзор **уведомление о начале обработки персональных данных** —
>    сайт собирает имя и телефон. За неподачу штраф для юрлиц 100–300 тыс. руб.

## 11. Медиа

**Видео героя.** Исходник весил 7.6 МБ и содержал ненужную аудиодорожку (видео всегда
muted). Пережато в 1.7 МБ без потери разрешения:

```bash
ffmpeg -i input.mp4 -an -c:v libx264 -crf 30 -preset slow \
  -pix_fmt yuv420p -movflags +faststart public/media/hero.mp4
```

`-an` убирает звук, `+faststart` позволяет начать проигрывание до полной загрузки.
Для нового видео используйте те же параметры и держитесь в пределах 2–3 МБ.

**Фото.** Владелец прислал 35 реальных снимков (архив `erklez.zip`). Использованы:
- `public/media/catalog/` — по 3 фото на бирюзу, зелёный и тёмный;
- `public/media/gallery/` — 10 фото для ленты (высота 640 px).

**Кэш:** `/media/*` отдаётся с `Cache-Control: immutable` на год (`next.config.mjs`).
